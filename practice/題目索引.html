上機考題目索引

看題目 → 找到對應資料夾 → 打開 practice/資料夾/ 裡的程式碼。藍色 LabN_ex = 課堂 Exercise 原題;綠色 LabN_gK = 猜題(g1 最可能)。每個資料夾的 README.md 有完整解說與易錯點。

看到題目怎麼找資料夾

步驟:① 用關鍵字認出 Lab → ② 用特徵挑最像的題目 → ③ 打開資料夾,從那份程式改,不要從零寫。

① 判斷是哪個 Lab

題目出現這些字 Lab
shell、.sh、bash、echo、read、$1 Lab 1
system call、syscall、SYSCALL_DEFINE、462、dmesg、重編 kernel Lab 2
只能用 <unistd.h>、open/read/write/close、fd、權限、strace Lab 3
library、.a、.so、static、dynamic、shared、ar、ldd Lab 4
kernel module、.ko、insmod、rmmod、module_param、EXPORT_SYMBOL Lab 5
process、fork、wait、PID/PPID、process tree、exec Lab 6
message queue、mq_、shared memory、shm_、mmap、sender/receiver、producer/consumer Lab 7

資料夾全名是 Lab{編號}_{上表代號},例如 Lab 6 的 g3 就是 practice/Lab6_g3/。

③ 打開資料夾後

  1. 先看 README.md 的「題目」,和考卷對照,找出不同的地方。
  2. 複製程式到自己的資料夾,只改不同的部分。
  3. 考前看過 README 最後的「容易踩的坑」。

都不太像? 先看 LabN_ex(原題)。所有猜題都是從原題變形來的,骨架一定用得上。

Lab6_g6fork() 連續呼叫 n 次，總共有幾個 process？猜題可能性:低～中
檔案:q6_count.c · 出處:review/predict/Lab6_predict.md

題目：執行下面的程式，回答總共會印出幾行？畫出 process tree。（或者反過來：寫程式讓每個 process 都印出 PID/PPID，再數一數總共有幾個。）

    fork();

答案：每呼叫一次 fork，process 數就乘以 2，所以總共 2³ = 8 個 process，印 8 行。樹的形狀（P0 是原始 process）：

P0 ─┬─ P1 ─┬─ P3 ── P7
    │      └─ P4
    ├─ P2 ── P5
    └─ P6
（P0 有 3 個 child，第一個 child 有 2 個，依此類推：3, 2, 1, 1, 0, 0, 0, 0）

Lab7_g6驗證觀念：kernel persistence 與 MAP_PRIVATE vs MAP_SHARED猜題可能性:中低
檔案:cleaner.c reader.c writer.c · 出處:review/predict/Lab7_predict.md
  1. writer.c：建立 shared memory，寫入 "original data" 後直接結束（不 unlink）。用 ls /dev/shm 證明 process 結束後物件仍存在。
  2. reader.c：先用 MAP_PRIVATE（PROT_READ|PROT_WRITE）映射並修改內容，再用 MAP_SHARED 映射同一個物件，印出內容，證明 MAP_PRIVATE 的修改不會影響到 shared memory；接著用 MAP_SHARED 修改。再執行一次 reader 證明 MAP_SHARED 的修改有留下來。
  3. cleaner.c：印出最終內容並 shm_unlink，之後 ls /dev/shm 看不到物件。

$ ./writer

$ ls /dev/shm

$ ./reader
[PRIVATE] before: original data
[PRIVATE] after : modified by MAP_PRIVATE
[SHARED ] content: original data
[SHARED ] after : modified by MAP_SHARED
$ ./reader
[PRIVATE] before: modified by MAP_SHARED
[PRIVATE] after : modified by MAP_PRIVATE
[SHARED ] content: modified by MAP_SHARED
[SHARED ] after : modified by MAP_SHARED
$ ./cleaner
cleaner: final content = modified by MAP_SHARED
cleaner: shm_unlink done
