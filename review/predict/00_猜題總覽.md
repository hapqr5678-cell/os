# 上機考猜題總覽

> 各 lab 詳細題目、參考答案、易踩的坑、考前 5 分鐘速查,請看同目錄的 `LabN_predict.md`。

## 共通出題邏輯

1. **換題不換機制**:核心 API/指令不變,只換題目內容(add/sub → sort、hello → 印 n 次)。
2. **用來驗證一個觀念**:fork 複製記憶體、static 比 dynamic 大、library 包裝 syscall 的價值。
3. **串連該 lab 所有小節**:題目會明確指定要用哪些語法/API。
4. **最可能的變形點 = 簡報教了、但 exercise 沒考到的東西**(見下表「下一個變形點」欄)。
5. 範圍只限簡報內容。

## 各 lab 最可能的題目

| Lab | 主題 | 最可能(高) | 下一個變形點 | 驗證 |
|---|---|---|---|---|
| 1 | Shell Script | 猜數字原題;範圍/次數改用 `$1 $2 $3 $#` 給並計次 | `case` 選單計算機(`\*`)、pipe + `while read` | ✅ bash/sh 實跑 |
| 2 | System Call | `SYSCALL_DEFINE1` 印 n 次 hello;`SYSCALL_DEFINE2` 兩數相加並回傳 | 要改哪 5 個檔案的流程題、新增第二個 syscall | ⚠️ kernel 端無法驗證,test.c 已編譯 |

| 4 | Library | 降冪排序 static+dynamic 再 `ls -l`;max/min/avg 多個 .o 包成 library | 重現找不到 .so 再修好 + `ldd`;更新 library 比較行為 | ✅ gcc/ar 實跑 |

## 重要提醒

- **Lab 2**:syscall 編號 462 在 v7.1.3 很可能已被占用(較新 kernel 中 462 是 `mseal`,未查證)。考試先 `grep` `syscall_64.tbl` 確認,以助教要求為準。
- **Lab 5**:投影片 p.33 範例的 `ts` 數字不是 Unix 時間戳,自己算出來和範例對不上是正常的。
- **Lab 6 Ex1**:對照 p.24 截圖,`practice/lab6/ex1.c` 是對的(只有 child 遞增,parent 仍是 10)。
- **Lab 7**:簡報範例程式本身有 bug(7-1 p.18 buffer 1000 卻傳 8192;7-2 p.23 buffer 未初始化;p.24 用 `%p` 印位址),不要照抄。
- **Lab 1**:`for ((...))`、`((i++))` 一定要 `#!/bin/bash`,Ubuntu 的 `/bin/sh` 是 dash。
