### 2.4 常見回傳值口訣
- **-1 + errno**：幾乎所有 system call 失敗的回傳方式（`open read write close fork wait exec mq_* shm_open ftruncate munmap`）。
- **例外**：`fopen` 失敗回 **NULL**、`fclose` 失敗回 **EOF**、`mmap` 失敗回 **MAP_FAILED**、`mq_open` 失敗回 **(mqd_t)-1**、shell `test` 成功回 **0**。
- **0 有特殊意義**：`read()` 回 0 = EOF；`fork()` 回 0 = 我是 child；kernel module `init` 回 0 = 成功。

## 3. 上機考常見步驟（依投影片實際教法）

### 3.1 一般 C 程式編譯
```bash
gcc prog.c -o prog          # 基本編譯
./prog
make prog                   # 沒有 Makefile 時 make 也能用內建規則編 prog.c（Lab2 的 make test）
gcc -c a.c                  # 只編成 a.o 不連結
gcc prog.c -o prog -lrt     # 用到 mq_* / shm_* 時（Lab7）
```
gcc 參數一覽：
| 參數 | 意義 |
|---|---|
| `-o name` | 指定輸出檔名 |
| `-c` | 只編譯不連結，產生 `.o` |
| `-fPIC` | 產生位置無關碼（做 .so 用） |
| `-shared` | 產生 shared library |
| `-L.` | 連結時去目前目錄找 library |
| `-lrt` | 連結 librt（POSIX IPC） |
| `-l名稱`（補充） | 連結 `lib名稱.so/.a` |
| `-Wall`（補充） | 開啟警告，考場除錯好用 |

### 3.2 Shell script（Lab1）
```bash
vim run.sh                  # 第一行 #!/bin/bash
chmod u+x run.sh
./run.sh 參數1 參數2
```

### 3.3 Static library（Lab4）
```bash
gcc -c sort.c                       # sort.o
ar rcs exlib.a sort.o               # 打包
gcc exercise.c -L. exlib.a -o exercise1
./exercise1
```

### 3.4 Shared library（Lab4）
```bash
gcc -c -fPIC sort.c
gcc sort.o -shared -o exlib.so
gcc exercise.c -L. exlib.so -o exercise2
sudo cp exlib.so /lib/exlib.so      # 否則執行時 cannot open shared object file
./exercise2
ldd exercise2
ls -l                               # 比較大小
```

### 3.5 新增 system call（Lab2）
```bash
cd ~/linux
mkdir hello; vim hello/hello.c; echo 'obj-y += hello.o' > hello/Makefile
vim include/linux/syscalls.h        # asmlinkage long sys_hello(void);
vim Kbuild                          # obj-y += hello/
vim arch/x86/entry/syscalls/syscall_64.tbl   # 462 common hello sys_hello
cp /boot/config-$(uname -r) .config
make olddefconfig
make localmodconfig
make -j $(nproc)
sudo make -j $(nproc) modules_install
sudo make install
reboot                              # GRUB（按住 Shift）→ Advanced options → 7.1.3-dirty
gcc test.c -o test && ./test        # 印 0
sudo dmesg | tail                   # 看到 Hello
```

### 3.6 Kernel module（Lab5）
Makefile（指令前是 **TAB**）：
```make
obj-m += date2timestamp.o
obj-m += myage.o

all:
	make -C /lib/modules/$(shell uname -r)/build M=$(PWD) modules
clean:
	make -C /lib/modules/$(shell uname -r)/build M=$(PWD) clean
```
```bash
make
modinfo date2timestamp.ko
sudo insmod date2timestamp.ko year=2001 month=8 date=1   # 參數不要寫 08
sudo insmod myage.ko                # 依賴者後載入
lsmod | head
sudo dmesg | tail -3
sudo rmmod myage                    # 依賴者先卸載；rmmod 不加 .ko
sudo rmmod date2timestamp
make clean
```

### 3.7 Process（Lab6）
```bash
gcc ex1.c -o ex1 && ./ex1
gcc ex2.c -o ex2 && ./ex2
```
模板：
```c
pid_t pid = fork();
if (pid < 0)       { perror("fork"); exit(1); }
else if (pid == 0) { /* child */ ...; exit(0); }   /* child 記得 exit！ */
else               { wait(NULL); /* parent */ ... }
```

### 3.8 IPC（Lab7）
```bash
gcc sender.c -o sender -lrt;     gcc receiver.c -o receiver -lrt
./receiver   # terminal 1
./sender     # terminal 2（Ctrl+Shift+T 開分頁），輸入 exit 結束
gcc -o producer producer.c -lrt; gcc -o consumer consumer.c -lrt
./producer && ./consumer
```

### 3.9 Makefile 格式（Lab2、Lab5）
```make
target: dependencies
<TAB>command
```
`make` 預設執行第一個 target（`all`）；`make clean` 執行 clean。**command 前必須是 TAB。**

## 4. 最容易被考的觀念對比（筆試速記）

| 對比 | 重點 |
|---|---|
| System call vs Library function | syscall 進 kernel（如 `write`）；library 在 user space 包裝 syscall（如 `printf`、`fwrite`），可加 buffer 減少 syscall 次數 |
| `read()` vs `fread()` | fread 有 user-space buffer，一次 read 4096 bytes，syscall 次數少很多 → 快 |
| fd vs `FILE*` | int（system call） vs stream 指標（C library） |
| Static vs Shared library | 連結時複製（大、快、獨立、更新要重編） vs 執行時載入（小、省空間、可共用、更新換檔、相依性問題） |
| `obj-y` vs `obj-m` | 編進 kernel（重編+reboot） vs 編成 .ko（insmod 動態載入） |
| Kernel module vs User program | `init_module`/`cleanup_module` vs `main`；`printk`→dmesg vs `printf`→terminal；kernel space 無 libc，出錯可能整台當機 |
| `insmod` vs `rmmod` | `insmod x.ko`（含 .ko） vs `rmmod x`（不含 .ko） |
| fork vs exec | fork 複製出新 process（PID 不同、內容一樣）；exec 在同一個 process（PID 不變）換上新程式 |
| fork 後的變數 | global、local、heap **全部複製**，互不影響 |
| `mq_close` vs `mq_unlink` | 關閉 descriptor vs 刪除 queue（名稱） |
| Message queue vs Shared memory | kernel 複製訊息、自帶同步 vs 直接共用記憶體、最快、要自己同步 |
| `MAP_SHARED` vs `MAP_PRIVATE` | 修改他人可見 vs 私有 |
| Shell `test` 回傳值 vs C | 0 = true（shell） vs 0 = false（C） |

## 5. 考前 10 個「一定要記得」

1. Shell：`x=1`（不空格）、`[ "$a" = "$b" ]`（要空格）、``x=`expr $x + 1` ``、`expr 2 \* 3`。
2. Vim：`i` 編輯、`Esc` 回 normal、`:wq` 存檔離開。
3. `fork()`：parent 得 child PID、child 得 0、失敗 -1；有幾個 child 就 wait 幾次；child 分支要 exit。
4. `execlp("ls", "ls", "-l", NULL)`——最後的 NULL 不能忘；成功就不返回。
5. `read` 回 0 = EOF；`open` 的 mode 是八進位 `0644`。
6. static：`gcc -c` → `ar rcs lib.a *.o` → `gcc main.c -L. lib.a -o x`；shared：`gcc -c -fPIC` → `gcc *.o -shared -o lib.so` → `gcc main.c -L. lib.so -o x` → `sudo cp lib.so /lib/`。
7. module：Makefile `obj-m`、`insmod x.ko`、`rmmod x`、`dmesg | tail`、init 回 `-EINVAL` 中止；export 符號的 module 先載後卸。
8. syscall：`SYSCALL_DEFINEn`、`asmlinkage`、`syscall_64.tbl`、`Kbuild`、重編+install+reboot，`syscall(462)` 回 0、訊息在 dmesg。
9. MQ：`mq_send(q, buf, strlen(buf)+1, 0)`、`mq_receive` 的長度 ≥ `mq_msgsize`、receiver 最後 `mq_close` + `mq_unlink`。
10. SHM：`shm_open → ftruncate → mmap(MAP_SHARED) → munmap → close`，讀方最後 `shm_unlink`；失敗比 `MAP_FAILED`；編譯加 `-lrt`。
